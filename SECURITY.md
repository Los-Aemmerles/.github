# Security

## Reporting a vulnerability

Please report security issues **privately** so we can address them before they are widely known.

**Do not** open a public GitHub issue for undisclosed security vulnerabilities.

### Contact

**Kinderspielstadt Los Ämmerles e.V.** — [developers@los-aemmerles.org](mailto:developers@los-aemmerles.org)

Include as much detail as you can: affected component, steps to reproduce, impact, and suggested fix if you have one. We will acknowledge receipt when possible; response times depend on volunteer availability.

## Scope

This policy applies to the open-source software in this repository. It does **not** cover production servers, live camp data, or third-party hosting — report those only if the issue is in **this codebase**.

## Safe disclosure

We appreciate responsible disclosure. We will not pursue legal action against researchers who report issues in good faith and avoid privacy violations (for example accessing real participant data on production systems).
