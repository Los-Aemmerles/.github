# Support

This page explains where to get help with **Kinderspielstadt Los Ämmerles e.V.** open-source software. Using the right channel keeps issue trackers focused on actionable bugs and feature work.

## Documentation

Start with the README in the repository you are working on:

For API and backend development, see the [la-server developer guide](https://github.com/Los-Aemmerles/la-server/blob/main/docs/developer-guide.md).

## Questions and general help

For **how-to questions**, setup problems, or anything that is not a confirmed software defect:

- Email [developers@los-aemmerles.org](mailto:developers@los-aemmerles.org)
- Visit [los-aemmerles.de](https://los-aemmerles.de)

Please **do not** open a GitHub issue for general questions — we are a volunteer team and email keeps support manageable.

## Bug reports

If you believe you found a **bug** in the software:

1. Search [existing issues](https://github.com/Los-Aemmerles) in the relevant repository.
2. If none match, open a **new issue** in that repository with steps to reproduce, expected vs. actual behaviour, and your environment (OS, app version, server version if applicable).

Do not include real camp data, participant names, or secrets in public issues.

## Feature requests

Ideas for new functionality belong in **Issues** in the repository where the change would land. Describe the problem you want to solve and, if you can, how you imagine it working during a camp week.

## Security vulnerabilities

**Do not** report security issues through public issues or this support address for general questions.

See [SECURITY.md](https://github.com/Los-Aemmerles/.github/blob/main/SECURITY.md) for private vulnerability reporting.

## Production and camp operations

Questions about **live camp operations**, hosting, or data handled during an actual Kinderspielstadt week are outside the scope of GitHub issues. Contact the association through [los-aemmerles.de](https://los-aemmerles.de) or [developers@los-aemmerles.org](mailto:developers@los-aemmerles.org).
