# Contributing

Thank you for helping **Kinderspielstadt Los Ämmerles e.V.** improve our open-source camp software.

## Before you start

- Code in our repositories is licensed under the [MIT license](https://opensource.org/licenses/MIT); by contributing you agree your contributions are under the same license.
- Read the repository **la-server** README and, for API work, [docs/developer-guide.md](https://github.com/Los-Aemmerles/la-server/blob/main/docs/developer-guide.md) where present.
- Do **not** commit secrets (`.env`), real camp data, or personal information.

## How to contribute

1. Open an **issue** to discuss larger changes, or pick an existing issue.
2. Fork the repository (or branch in-repo if you are a member).
3. Make focused changes; keep pull requests small when possible.
4. Run tests and pre-commit hooks locally if documented in the README.
5. Open a **pull request** against `main` with a clear description.

## Pull request checklist

- [ ] Tests pass (CI green)
- [ ] No secrets or real `village_data/` committed
- [ ] Documentation updated if behavior or API changed

## Code of conduct

Be respectful. This project serves a children's summer camp run by volunteers. Harassment or misuse of reported vulnerabilities is not tolerated.

## Security

See [SECURITY.md](https://github.com/Los-Aemmerles/.github/blob/main/SECURITY.md) for private vulnerability reporting.
