# Los-Aemmerles/.github

This repository is **`Los-Aemmerles/.github`** on GitHub — the [Kinderspielstadt Los Ämmerles e.V.](https://los-aemmerles.de) organisation profile and default community files.

## Publish / update

Clone and push from this folder (`GitHub-Organisation/`):

```bash
cd GitHub-Organisation
git add .
git commit -m "Update organisation profile"
git push origin main
```

**Convention:** GitHub accepts community health files at the repository root, in `.github/`, or in `docs/`; only `profile/README.md` and `.github/ISSUE_TEMPLATE/` have fixed locations. In this repo, human-facing docs (`README`, `CONTRIBUTING`, `SECURITY`, and similar) stay at the root so they appear on the landing page; machine-consumed config (`FUNDING.yml`, `ISSUE_TEMPLATE/`, `pull_request_template.md`, workflows) lives under `.github/`. Other paths such as `profile/` and `assets/` stay at the repository root.
